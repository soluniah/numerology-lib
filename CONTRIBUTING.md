# Contribution Guidelines

Thank you for considering contributing to numerology! To maintain the quality and consistency of this project, please follow these guidelines.

## General Rules

- All contributions must be reviewed and approved before being merged.
- Redistribution of derived versions without authorization is not allowed.
- Proper attribution is required in all uses of the code.

## How to Contribute

1. Fork the repository and clone your fork.

```
git checkout -b feature/new-feature
```

2. Make your changes, following the project's coding standards.
3. Write tests for new features or bug fixes.
4. Ensure all tests pass before submitting a Pull Request.

```
pytest
```

5. Submit a Pull Request with detailed information about your changes.

## Development

Install the package with development dependencies:

```
pip install -e ".[dev]"
```

Run the test suite:

```
pytest
```

## Pull Request Review

- The maintainers will review your contribution as soon as possible.
- You might be asked to make adjustments before the PR is merged.
- By submitting a PR, you agree that your contribution will be licensed under the same license as the project.

## Prohibited Actions

- Do not clone or publish the project as your own.
- Do not use the project for commercial purposes without prior authorization.
